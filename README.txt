# SpaceClicker

SpaceClicker est **simple d'utilisation**.

## Utilisation

Vous devez renseigner :

- dans la **1ère case**, le nombre de **secondes** entre chaque clic ;
- dans la **2ème case**, le nombre de **minutes** ;
- dans la **3ème case**, le nombre d'**heures**.

## Dev

SpaceClicker a été développé en **C# .NET 10** avec **WPF**.
